# 知能検査 見立てナビ（WISC対応）

WISC-V・WISC-IV・WISC-IIIの報告書にある数値（全検査IQ・指標得点・評価点）を入れると、力のバランス、学校・家庭での手立ての候補、版をまたいだ比較を表示する先生向けの参考ツールです。

- 無料・アカウント登録不要
- 入力したデータは、使う人のブラウザの中だけに保存されます（外部には送られません）
- 教師向け見立てシート、検査の説明シートをA4一枚のPDFで保存できます

## ご利用にあたって
このアプリは、先生が検査の報告書を読み取るための参考ツールとして、個人が作成したものです。診断や、専門家（検査者）の解釈に代わるものではありません。表示される見立てや手立ては一般的な目安で、正確さを保証するものではありません。ご利用は各自の責任でお願いします。このアプリの利用によって生じた結果について、作成者は責任を負いかねます。
